R4ENC / OpenH264
=================
R4ENC.R4L includes the encoder, common utilities and x86 assembly from
Cisco OpenH264 2.6.0, built from the original source archive:
https://github.com/cisco/openh264/archive/refs/tags/v2.6.0.tar.gz
SHA256: 558544ad358283a7ab2930d69a9ceddf913f4a51ee9bf1bfb9e377322af81a69

The original BSD-2-Clause source license is reproduced in
OpenH264-BSD-2-Clause.txt. Original per-file copyright notices remain in the
prepared sources. This is an R4OS source build, not a Cisco binary package.
The source pin, source plan, preparation patch and build scripts are in
Repositories/Libraries/R4ENC/{ThirdParty,Tools,Port}. Shared formatting uses
stb_sprintf with its original MIT/Unlicense notices in R4NAK-NOTICES.txt.
The shared musl-derived math provider retains NATIVE-MATH-NOTICES.txt.
Original R4OS adapters, ownership and orchestration remain Apache-2.0.

The R4OS patch selects the freestanding C11 mutex and monotonic clock
adapters and excludes the upstream host/global-thread-pool execution path.
The original H.264 compression algorithms and CPU SIMD dispatch remain.

AMD VCN1 encoder sources
------------------------
R4ENC also compiles unchanged Mesa26.2.2 VCN1 session, header, slice-template
and rate-control functions and metadata, plus original R4OS bounded adapters.
Exact source bytes/hashes: Libraries/R4AMD/ThirdParty/Sources.json.
Extraction and native build: R4AMD/Tools/VcnEncode.ps1 and
R4ENC/Tools/BuildNative.ps1. Original AMD/Younes Manton and related MIT
notices and complete permission grants accompany R4AMD-NOTICES.txt.
This code is independent of the OpenH264 software path and does not add
FFmpeg or a new copyleft dependency to R4ENC.
